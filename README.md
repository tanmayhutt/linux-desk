# Linux Desk

An interactive Hyprland-inspired portfolio built with plain HTML, CSS, and JavaScript.

The site includes four workspaces, draggable windows, a Wofi-style launcher, terminal tools, a theme selector, responsive touch controls, and a GitHub-backed project view.

Open the launcher from the Waybar, use the numbered workspace controls, or move between workspaces with the side arrows. No build step is required.
